🧹 MaidLedger — 數據庫架構與資料流程

更新日期：2026-05-22 | 來源：supabase/migrations/

🎯 統一 Schema 目標：Chat 和 Scan 寫入完全相同的 tables——只是輸入方式不同。所有收據條目都經過：receipts → receipt_items → master_products + product_aliases，同時更新 shops + shop_aliases 和 price_history。

📊 實體概覽

👤 user_profiles（用戶資料）

idUUID 主鍵→ auth.users
TEXT角色：雇主|幫手
TEXT姓名、電話
VARCHAR(20)short_code（唯一）

系統身份 + 僱主邀請碼

🔗 employer_helper_relations（僱主-幫手關係）

idUUID 主鍵
employer_idUUID 外鍵→ user_profiles
helper_idUUID 外鍵→ user_profiles
TEXT狀態：active|inactive|pending

連接僱主 ↔ 幫手。UNIQUE(employer_id, helper_id)

🧾 receipts（收據）

idUUID 主鍵
employer_idUUID 外鍵→ user_profiles
helper_idUUID 外鍵→ user_profiles
relation_idUUID 外鍵→ employer_helper_relations
shop_idUUID 外鍵→ shops（可為空）
TEXTstore_name、store_cate、location
DATE交易日期
TEXTraw_text（完整 OCR/Chat 文字）
DECIMALamount（總額）
TEXTsync_status: pending|synced
BIGINTlocal_timestamp（本地時間戳）
TEXTimage_local_path（本地路徑，未上傳）

收據主表。Chat 和 Scan 寫入相同欄位

📦 receipt_items（收據項目）

idUUID 主鍵
receipt_idUUID 外鍵→ receipts ON DELETE CASCADE
master_product_idUUID 外鍵→ master_products（可為空）
TEXTitem_name（LLM 翻譯成中文）
TEXTitem_raw_text（原始 OCR/Chat 文字）
DECIMALqty、unit_price、line_total
TEXTprd_cate：魚|豬肉|牛肉|雞肉|蔬菜|...

收據項目（1:N）。LLM 將 item_name 翻譯成中文

🏪 shops（店鋪）

idUUID 主鍵
TEXTcanonical_name（標準化名稱）
TEXTshop_type：超市|街市|藥房|...
TEXTregion、district

標準化店名。爬蟲從抓取建立，幫手 App 從 OCR 店名建立

🏷️ shop_aliases（店鋪別名）

idUUID 主鍵
TEXT 唯一raw_name（原始名稱）
shop_idUUID 外鍵→ shops ON DELETE CASCADE
TEXTsource：ocr|crawler|manual|seed

將所有原始店名映射到標準店名，支援 ILIKE 匹配

🛒 master_products（主產品）

idUUID 主鍵
TEXTcanonical_name（標準化名稱）
TEXTbrand、prd_cate、default_unit
TEXT[]search_keywords（ILIKE 匹配用）

標準化產品定義。爬蟲和幫手 App 共用

🏷️ product_aliases（產品別名）

idUUID 主鍵
TEXT 唯一raw_name（原始 OCR/爬蟲/Chat 文字）
master_product_idUUID 外鍵→ master_products ON DELETE CASCADE
TEXTsource：ocr|crawler|manual|seed

將所有原始產品名映射到標準 master_products。ILIKE 匹配層

💰 price_history（價格歷史）

idUUID 主鍵
master_product_idUUID 外鍵→ master_products ON DELETE CASCADE
shop_idUUID 外鍵→ shops ON DELETE SET NULL
TEXTlocation、region
DECIMALprice、unit
source_receipt_idUUID 外鍵→ receipts ON DELETE SET NULL
DATErecorded_at（預設：當前日期）
TEXTsource_type：receipt|scraper

統一價格記錄。爬蟲 + 幫手 App 都寫入，方便比價

📥 幫手 App 輸入流程（Chat）

  1. 用戶輸入：「魚 30蚊」
  2. → chat-parser Edge Function（LLM）
  3. → receipts（寫入）
  4. → receipt_items（寫入）
  5. → ShopMatchingService.matchShop() → shops + shop_aliases
  6. → ProductMatchingService.matchItem() → master_products + product_aliases
  7. → price_history（寫入，source_type='receipt'）
  8. → notification-broadcast → Realtime 通知僱主

📷 幫手 App 輸入流程（Scan）

  1. 用戶拍攝圖片 → ML Kit OCR
  2. → receipt-parser Edge Function（LLM）
  3. → receipts（寫入）
  4. → receipt_items（寫入）
  5. → ShopMatchingService.matchShop() → shops + shop_aliases
  6. → ProductMatchingService.matchItem() → master_products + product_aliases
  7. → price_history（寫入，source_type='receipt'）
  8. → notification-broadcast → Realtime 通知僱主

🕷️ 爬蟲流程

  1. Python + Playwright 抓取 HKTVmall / 惠康 / 百佳
  2. → shops（insert/update）
  3. → shop_aliases（insert）
  4. → master_products（insert/update）
  5. → product_aliases（insert）
  6. → price_history（insert，source_type='scraper'）

🔔 即時通知流程

  1. Helper 寫入 receipts → Supabase Realtime 監聽
  2. → notification-broadcast Edge Function
  3. → 查詢僱主 device token
  4. → 發送 Firebase FCM / APNs 推送

🗝️ RLS Policies（行級安全）

TablePolicyCondition
receiptsHelper 只能睇自己寫的helper_id = auth.uid()
receipts僱主只能睇自己家庭的employer_id IN (SELECT employer_id FROM employer_helper_relations WHERE helper_id = auth.uid())
receipt_items跟隨 receiptsreceipt_id IN (SELECT id FROM receipts WHERE ...)
user_profiles所有人可讀自己id = auth.uid()
shops所有人可讀可寫無（已設定為 public）
master_products所有人可讀，認證用戶可寫Authenticated 可 insert
price_history所有人可讀可寫無（已設定為 public）

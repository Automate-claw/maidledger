🧹 MaidLedger — Database Schema & Data Flow

Last updated: 2026-05-22 | Source: supabase/migrations/

🎯 Unified Schema Goal: Chat and Scan write to the exact same tables — only input method differs. All receipt entries flow through: receipts → receipt_items → master_products + product_aliases, with shops + shop_aliases and price_history updated in parallel.

📥 Helper Input Flow (Chat)

  1. User types: "魚 30蚊"
  2. → chat-parser edge function (LLM)
  3. → receipts (insert)
  4. → receipt_items (insert)
  5. → ShopMatchingService.matchShop() → shops + shop_aliases
  6. → ProductMatchingService.matchItem() → master_products + product_aliases
  7. → price_history (insert, source_type='receipt')
  8. → notification-broadcast → Realtime to employer

📷 Helper Input Flow (Scan)

  1. User captures image → ML Kit OCR
  2. → receipt-parser edge function (LLM)
  3. → receipts (insert)
  4. → receipt_items (insert)
  5. → ShopMatchingService.matchShop() → shops + shop_aliases
  6. → ProductMatchingService.matchItem() → master_products + product_aliases
  7. → price_history (insert, source_type='receipt')
  8. → notification-broadcast → Realtime to employer

🕷️ Scraper Flow

  1. Python + Playwright crawl HKTVmall/Wellcome/ParknShop
  2. → ShopMatchingService → shops + shop_aliases (source='crawler')
  3. → ProductMatchingService → master_products + product_aliases (source='crawler')
  4. → price_history (insert, source_type='scraper')
  5. → price-alert-engine can now compare (scraper vs receipt)

🔑 Unification key: Both source_type='receipt' (from helper) and source_type='scraper' (from scraper) write here. price-alert-engine queries this table to compare helper purchase price vs HK avg price.

🔄 Price Alert Workflow

Helper buys "🐟 紅衫魚 $40"

Step 1: receipt saved → receipt_items.master_product_id = [matched fish id]
Step 2: price_history.insert (source_type='receipt')
Step 3: price-alert-engine queries:
  SELECT AVG(price), MIN, MAX
  FROM price_history
  WHERE master_product_id = [fish]
    AND recorded_at > NOW() - 7 days
    AND source_type = 'scraper'  ← only HK market prices

Result:
  avg=$35, min=$28, max=$45
  helper paid $40 → 14% above avg → ⚠️ YELLOW alert

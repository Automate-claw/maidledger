⚠️ 核心問題分析

❌ Bug: unit 欄位定義模糊

位置：price_history.unit

問題：用戶揀 500g，但寫入時變成 "件"。selectedWeights 傳遞鏈斷咗。

根因：chat_screen._saveExpense() 收到 _selectedWeights 但冇傳俾 aiAgent.saveExpense()

⚠️ 架構: price_history.unit 是 free-text

問題：冇標準化，無法做 cross-product price comparison

建議：加 weight_g (int) + unit_display (text)，加 price_per_kg (numeric)

⚠️ 架構: 兩條路寫 price_history

位置：chat_screen._matchProductsAndWritePriceHistory() 直接寫 DB

問題：繞過 edge function，business logic 分散

建議：全部經 receipt-writer edge function

⚠️ 架構: receipt_items 缺少 weight 欄位

問題：LLM extracted_spec 係文字 ("斤")，冇標準克數

建議：加 weight_g (int) + extracted_spec (text, 顯示用)

Migration: 030_fix_unit_schema

🗄️ 核心 Schema 關係圖

用戶身份 → 關係 → 收據 → 項目

👤 user_profiles ──1:N── 🔗 employer_helper_relations ──1:N── 🧾 receipts ──1:N── 📦 receipt_items
📦 receipt_items ──→── 🛒 master_products ──←── 🏷️ product_aliases
🧾 receipts ──→── 🏪 shops ──←── 🏷️ shop_aliases

價格流向（Receipt + Scraper → 統一 price_history）

📷 Helper 掃描收據 → 🧾 receipts → 📦 receipt_items → 💰 price_history source=receipt
🕷️ Scraper 爬蟲 → 💰 price_history source=scraper
💰 price_history ──→── 🛒 master_products ──←── 🏪 shops

👤 user_profiles

idUUID PK→ auth.users

TEXTname, phone
VARCHAR(20)short_code（唯一）

idUUID PK

UNIQUE(employer_id, helper_id)

idUUID PK
employer_idUUID FK→ user_profiles

DECIMALparse_confidence

🔄 主要工作流程

Chat Flow（文字 → 收據）

步驟ComponentAction
1Helper App用戶輸入「魚 30蚊」
2ai_booking_agent_service→ chat-orchestrate
3chat-orchestrateLLM 解析（is_expense?）
4chat-orchestrateRate limit check
5receipt-writercreateFromChat → receipts
6receipt-writerwriteItemsFromChat → receipt_items
7shop-managerupsert → shops + shop_aliases
8product-managerupsert → master_products + product_aliases
9receipt-writerwritePriceHistory → price_history
10notification-broadcast→ Employer App（非阻塞）

Scan Flow（圖片 → 收據，Event-Driven）

步驟ComponentAction
1Helper AppCamera → ML Kit OCR → receipt-parse
2receipt-parseLLM Vision → receipt-orchestrate webhook
3receipt-orchestrateDB Trigger → lock（parse_status: pending→processing）
4receipt-orchestrateLLM Vision Parse（qwen3-vl-30b）
5receipt-orchestrateShop matching（Step 3b，早於 product）
6receipt-orchestrateINSERT receipt_items（batch）
7receipt-orchestrateProduct matching + price_history（per item）
8notification-broadcast→ Employer App
—Fallback Cron每5分鐘撈取 parse_status=pending 記錄

Scraper Flow（Python → price_history）

步驟ComponentAction
1scraper.pyPlaywright 爬取 HKTVmall / 惠康 / 百佳
2scraper.py→ shops + shop_aliases（insert/update）
3scraper.py→ master_products + product_aliases（insert/update）
4scraper.py→ price_history（source_type='scraper'）
